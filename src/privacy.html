隐私政策

最后更新日期：2026年6月2日

欢迎使用 MD ↔ HTML 转换器（以下简称"本工具"）。我们非常重视您的隐私保护。

1. 信息收集

我们不收集任何个人信息。

  • 所有 Markdown 和 HTML 内容均在您的浏览器本地处理，不会上传到服务器
  • 我们不使用 Cookie 追踪您的行为
  • 我们不要求用户注册账户或提供任何个人信息

2. 数据处理

所有数据处理均在您的浏览器本地完成：

  • Markdown ↔ HTML 转换完全在本地运行
  • PDF、Word 等文件导出使用浏览器端 JavaScript 库
  • 关闭浏览器标签页后，所有输入数据将被自动清除

3. 广告与 Cookie

本工具使用 Google AdSense 展示广告。请注意：

  • Google AdSense 可能会使用 Cookie 或类似技术来展示个性化广告
  • 您可以访问 Google 广告设置 来管理广告偏好

4. 第三方服务

本工具使用以下第三方服务：

  • Google AdSense：广告服务平台
  • Vercel：网站托管服务

5. 联系我们

如有任何隐私相关疑问，请通过 GitHub 联系我们。
