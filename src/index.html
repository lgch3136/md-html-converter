📖 Markdown 语法速查

不熟悉 Markdown？以下是常用语法快速参考，帮助你快速上手编辑。

标题

# 一级标题 ## 二级标题 ### 三级标题

使用 1~6 个 # 号标记不同级别标题，对应 HTML 的 h1~h6。

文字样式

**加粗文字** *斜体文字* ~~删除线~~ `行内代码`

双星号加粗、单星号斜体、双波浪线删除。` 反引号包裹行内代码。

列表

- 无序项目一 - 无序项目二 1. 有序项目一 2. 有序项目二 - [ ] 待办任务 - [x] 已完成

用 - 或 * 创建无序列表，用数字加点创建有序列表。- [ ] 可创建任务清单。

引用

> 这是一段引用文字 > 可以多行 >> 嵌套引用

使用 > 符号标记引用块，常用于摘录或强调。

链接与图片

[链接文字](https://example.com) ![图片描述](image-url)

方括号写显示文字，圆括号写 URL。图片语法前面多一个 !。编辑器也支持直接 Ctrl+V 粘贴图片。

代码块

```javascript console.log('Hello'); ```

使用三个反引号包裹代码，可在开头指定语言名称以获得语法高亮。

表格

| 姓名 | 年龄 | |------|------| | 张三 | 28 |

用 | 分隔列，第二行用 --- 定义对齐方式。编辑器也支持可视化插入表格。

分割线

--- ***

三个或以上 - 或 * 创建水平分割线。

💡 提示：如果你不想记语法，可以直接在编辑器中使用工具栏按钮进行可视化编辑——编辑器会自动生成对应的 Markdown 代码。

❓ 常见问题 FAQ

这个工具是免费的吗？

是的，完全免费使用。我们通过非侵入式广告维持服务器和带宽成本，所有核心功能永久免费。无需注册、无需登录、无使用次数限制。

我的数据安全吗？会上传到服务器吗？

你的数据绝对安全。本工具所有数据处理均在浏览器本地完成——Markdown 转换、HTML 渲染、文件导入导出全部在客户端执行，绝不将你的内容上传到任何服务器。关闭标签页后所有数据自动清除。

Markdown 和 HTML 有什么区别？什么时候用哪个？

Markdown 是一种轻量级标记语言，语法简单直观，适合快速写作（如博客、笔记、文档）。HTML 是网页的标准语言，功能更强大但语法复杂。一般情况下，日常写作推荐使用 Markdown；需要发布到网页、或需要复杂排版时，可以转换为 HTML。

支持哪些文件格式的导入和导出？

支持导入：Markdown (.md)、HTML (.html)、纯文本 (.txt)、Word (.docx)。支持导出：PDF (.pdf)、Word (.docx)、独立 HTML (.html)、Markdown (.md)、纯文本 (.txt)。

可以插入图片和视频吗？

可以。支持三种方式插入图片：粘贴板粘贴 (Ctrl+V)、拖拽文件到编辑区、工具栏上传按钮。视频方面，支持粘贴 Bilibili、YouTube 链接自动嵌入播放器。

导出的 PDF 和 Word 格式排版会丢失吗？

基本不会。导出功能会保留标题层级、加粗斜体、代码块高亮、表格、引用、图片、视频缩略图等格式。但复杂 CSS 样式可能无法完全保留——如需高度精确的排版，建议导出为 HTML 后在 Word 中打开。

在手机上可以使用吗？

可以。本工具采用响应式布局设计，自动适配桌面、平板和手机屏幕。在移动端编辑区域会切换为上下布局，方便使用。

除了在线版本，有离线版本或浏览器扩展吗？

目前仅提供在线版本。由于所有处理都在浏览器本地完成，你可以在首次加载后断网使用。未来会考虑发布 PWA 离线版本和浏览器扩展。
