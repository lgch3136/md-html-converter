✨ 核心功能

🔄

双向转换

Markdown 转 HTML、HTML 转 Markdown，一键切换，所见即所得。

📝

富文本编辑

支持加粗、斜体、标题、列表、引用、代码块、表格、图片、视频等完整富文本操作。

📤

多格式导出

支持导出为 PDF、Word 文档、独立 HTML、Markdown 原文、纯文本，满足各种场景需求。

📥

多格式导入

支持导入 .md、.html、.txt、.docx 文件，也可粘贴图片、拖拽文件到编辑区。

🎥

视频嵌入

支持粘贴 B 站、YouTube 视频链接，自动嵌入 iframe 播放器。

⌨️

快捷键支持

Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+S 转换等常用快捷键，操作更高效。

📰

公众号 / 知乎文章编辑

📊

技术文档撰写

支持代码高亮、表格、引用等语法，适合编写 API 文档和技术博客。

邮件与报告

将 Markdown 编写的报告转换为格式精美的 HTML 邮件正文。

🚀 使用方法

1

打开编辑器

点击上方「打开工具」按钮，进入在线编辑器页面。

2

输入或导入内容

在左侧输入 Markdown 源码，或通过导入按钮上传 .md、.html、.txt、.docx 文件。

3

实时预览与转换

点击中间的「转 HTML」按钮，右侧即时显示渲染效果。支持自由切换阅读/源码模式。

4

导出成果

选择 PDF、Word、HTML 等格式导出，也可复制 HTML 源码到其他平台使用。

🔧 技术细节

本工具基于纯前端技术构建，所有数据处理均在浏览器本地完成，不会上传任何用户数据到服务器。

  • 使用 marked 库进行 Markdown → HTML 转换
  • 使用 turndown 库进行 HTML → Markdown 转换
  • 使用 html2pdf.js 实现 PDF 导出
  • 使用 docx 库实现 Word 导出
  • 支持图片粘贴（Ctrl+V）和文件拖拽上传
  • 支持 Bilibili / YouTube 视频链接自动嵌入
